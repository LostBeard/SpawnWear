# SpawnWear
.Net software for ESP32-S3 watch using nanoFramework

## ESP32-S3
ESP32-S3 2.06inch AMOLED Touch Watch Development Board, 32-bit LX7 Dual-core Processor, 410×502 Pixels, QSPI Interface, Onboard Dual Digital Microphones Array, ESP32 With Display

## Software Features
- Wifi client
- Wifi AP support
- Bluetooth
- OTA Updates
- Battery charge handling
- Support for all sensors
- Useful easy to use UI
- Lower power usage is default
- Wake screen for time, turn off when not viewing (gyroscop to determin orientation)
